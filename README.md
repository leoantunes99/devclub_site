<h2 id="sobre-o-projeto">📌 Sobre o Projeto</h2>

O site **DevClub** é uma página institucional criada para fortalecer a presença online da comunidade, transmitir **autoridade, confiança e credibilidade**, além de apresentar os cursos e a proposta de transformação de carreira para novos alunos.

O projeto foi desenvolvido com foco em:

- **Captação de novos alunos**
- **Performance e carregamento rápido**
- **SEO para melhor posicionamento no Google**
- **Experiência fluida em desktop e mobile**
- **Animações interativas com GSAP**

A estrutura prioriza clareza das informações, apresentação dos diferenciais da comunidade (carrossel de logos de parceiros, bento-grid de recursos, gráficos de remuneração da área) e chamadas estratégicas para ação.

<h2 id="principais-funcionalidades">✨ Principais Funcionalidades</h2>

- ✅ Componentização com **React**
- ⚡ Build rápido e ambiente de desenvolvimento otimizado com **Vite**
- 🎨 Estilização moderna e responsiva com **Tailwind CSS**

<h2 id="modo-de-uso">▶️ Modo de Uso</h2>

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/devclub-site.git
```

2. Acesse a pasta do projeto:

```bash
cd devclub-site
```

3. Instale as dependências:

```bash
npm i
```

4. Rode o projeto em ambiente de desenvolvimento:

```bash
npm run dev
```

5. Acesse no navegador o endereço exibido no terminal (geralmente `http://localhost:5173`).
